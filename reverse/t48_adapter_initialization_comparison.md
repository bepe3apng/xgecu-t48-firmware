# Сравнение инициализации адаптеров T48

Статический разбор оригинального OR/Xgpro.exe 13.16, OR/InfoIC2Plus.dll и существующей декомпиляции T48. USB-команды не выполнялись, прошивка устройства не менялась. Физические уровни и распиновка прибором не измерены.

## Общая последовательность

В основном исследованном пути Xgpro проверка адаптера вызывается в 0x44537A (функция 0x458490), передача параметров USB03 — позднее в 0x4454DF (функция 0x444BC0). Для семейства eMMC есть дополнительная предварительная проверка 0x442320; изученный участок содержит проверки пользовательских параметров/файлов, его нельзя называть аппаратным init.

Аутентификация и рабочая инициализация — разные этапы. Проверка адаптера: USB24/F0 -> USB24/E0 с селектором -> сравнение ID на ПК -> USB24/F1. Затем USB03 сохраняет параметры чипа и вызывает обработчик семейства. Отдельные операции запускаются последующими командами.

## Различия подготовки крипточипа

Xgpro 0x4584D4..0x458566 выбирает F0 mode=1 для family 0x31 (eMMC); для найденных NOR-ветвей 0x12/0x13/0x15 и применимых NAND-ветвей 0x2D — mode=0. У NAND есть условие пропуска проверки; для family 0x34 проверка включается при selector=2. Нельзя распространять проверку на все записи этих семейств без учёта условий.

Прошивка FUN_0002AB30 направляет F0 в FUN_0002A364. Последняя настраивает GPIO, выполняет пробуждение крипточипа, затем завершает подготовительный обмен.

| Режим F0 | SDA: блок/маска | SCL: блок/маска | Дополнительно |
|---|---|---|---|
| 1, eMMC | 0x40011800 / 0x0001 | 0x40010C00 / 0x0200 | Отдельная пара GPIO |
| 0, основной путь | 0x40011000 / 0x0200 | 0x40011000 / 0x0100 | При ошибке wake есть резервная попытка |
| 0, резервная попытка | 0x40010C00 / 0x0001 | 0x40010C00 / 0x0002 | Другая конфигурация GPIO |

Это адреса и маски MCU, а не подтверждённые номера физических контактов адаптера. Замена E0 в V6 не удаляет F0 и его действия с GPIO.

## Сравнение eMMC-адаптеров

| Адаптер | Селектор E0 | Основной ожидаемый ID |
|---|---|---|
| BGA153 / BGA169 | E5000000 | ADA00009 |
| BGA162 | E6000000 | ADA0000A |
| BGA221 | E7000000 | ADA0000C |
| BGA100 | E8000000 | ADA0000B |
| ISP | 00004000 | ADA00008; допускается ADA00007 |
| SD-адаптер | EC000000 | ADA00007 или ADA00008 |

Некоторые BGA-ветви также принимают ID SD/ISP; это подтверждает общую инфраструктуру проверки, но не взаимозаменяемость электрических адаптеров.

В базе найдено 765 записей family 0x31 с BGA169 в имени: все имеют E5000000. Таким образом, BGA169 не требует отдельного от BGA153 ID в исследованной базе.

У AUTO-EMMC для BGA100/153/162/221 используются одинаковые группы режимов: 51 — 1 бит, 54 — 4 бита, 53 — 8 бит. У ISP — 41 для 1 бита и 44 для 4 бит. Это значения из базы; наличие имени .alg не доказывает загрузку файла в T48.

USB03 (FUN_0002BFB2) сохраняет параметры и выбирает обработчик по family. Для family 0x31 задаёт отдельное значение параметра размера 0x100000. Нельзя автоматически трактовать это значение как физическую ёмкость eMMC.

FUN_0001EA6C содержит подготовку eMMC: GPIO, задержки, запись параметра 2000A4EC, выбор состояний по 2000A4D6/2000A4E5/2000A4F0. Для групп 41/51 устанавливает внутренний режим 0, для остальных — 1. Точное электрическое значение каждого GPIO в рамках этой проверки не устанавливалось.

USB21 запускает FUN_0001EE78 для eMMC; отдельно предусмотрена ветвь SD при 2000A4E7=A3 (FUN_00021490). В исходной FUN_0001EE78 флаг gp-0x7AF (200000E9) разрешает запуск, иначе возвращается 2A. Далее настраиваются периферия/GPIO и вызывается FUN_0001EC4E: в ней видны начальные команды eMMC CMD0/CMD1 и ожидание готовности OCR. Последующие операции получают регистры и настраивают шину. Следовательно, правильный ID адаптера ещё не доказывает успешный запуск самой памяти.

## NOR/NAND и TSOP56

У NOR после USB03 настраиваются собственные линии адреса/данных/управления. Например, FUN_0001B62E назначает GPIO и корректирует конфигурацию при selector=1/2 и дополнительных параметрах.

FUN_0001B4EC имеет отдельную ветвь selector=0B: настройка масок зависит от параметра 2000A4C4 (<8, ==7, >=8) и 20009C1C. Есть отдельные ветви E3000000, E4000000, EA000000. Это доказывает, что селектор участвует не только в проверке ID: он влияет на рабочую конфигурацию NOR.

У NAND USB03 содержит отдельную ветвь family=2D. Полная последовательность всех NAND/PIC и прочих семейств в этом разборе не восстановлена; для них нельзя заявлять совпадение электрического запуска с eMMC.

## Значение для V6

V6 сохраняет исходный обработчик E0 для 0B, а для остальных подменяет ответ/статус. Передача селектора в USB03, обработчики рабочих семейств и общая GPIO-функция не заменяются. Обход контакта 40 остаётся в конкретном вызове проверки eMMC 3E01. Наследованный от V4 обход флага допуска eMMC также сохранён.

Сходство BGA100/162/221 с BGA153/169 делает общий обход проверки ID обоснованным по коду, но не доказывает аппаратную совместимость V6. F0 продолжает физические действия, контактные проверки и запуск чипа могут выявить самостоятельные ошибки. Проверка всех адаптеров на оборудовании не проводилась.
